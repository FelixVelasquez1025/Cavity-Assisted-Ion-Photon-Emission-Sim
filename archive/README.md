# Historical implementations

This directory preserves the original collaborative three-level model, calcium examples, and later development experiments.
The older UI, Hamiltonian helpers, batch tools, notebooks, and tests are kept for project history.
Their conventions and results are not equivalent to the current pulse-enabled Yb-171 model in `src/caipe_sim/`.
These files are excluded from the installed package and CI; optional historical dependencies and obsolete APIs may require a separate environment before use.
